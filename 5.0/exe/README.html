🍅 番茄钟 SE Orbit SE

绝对精简版：只保留最核心的学习计时与任务管理功能。

有什么

  • 选择模式：现在时间 / 学习模式 / 极简模式 / 我的学习记录（无加载进度条）
  • 任务管理器：管理学习任务，支持 rw 预设（单击选中 / 双击应用）
  • 更新日志：精简展示本版功能

去掉了什么

  • 挑战模式 / 考试模式 / 极简番茄 / 正计时
  • mod 系统（fqm / almfq）、小功能、教程、设置
  • 任务标签「正常学习 / 努力的我」与锁定
  • 选择模式的加载进度条

数据与保存

数据保存在程序目录下的 Orbit3_data.json。

  • 退出程序时自动保存
  • 每隔一段时间自动保存
  • 极简模式中途退出会结算已学习的时间
