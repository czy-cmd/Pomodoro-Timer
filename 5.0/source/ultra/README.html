番茄钟5.0（Orbit 3）

🍅 番茄钟5.0 Orbit 3

番茄钟 4.2（Orbit 2）的全面升级版：合并了任务管理器、鼠标检测器，并新增小功能、开发者模式、附件系统等。

三个版本

普通版 番茄钟 + 任务管理器 + 内存优化（一键回收）。最简洁，适合只想专注的人。

Pro 版 普通版 + 小功能（鼠标检测器 / 音乐 / 倒计时纪念日 / 随机决定器）+ 开发者模式 + 多开。

Ultra 版 Pro 版 + 附件系统（3 个可下载小工具）+ HTML 更新日志 + 更详细的崩溃日志。测试版，可能有 BUG。

主要功能

  • 学习模式：经典番茄钟，专注 / 休息循环
  • 任务管理器：管理学习任务，支持「努力的我」锁定标签、预设、多选
  • 小功能：鼠标检测器（专注/瞎玩计时）、音乐（自定义网址）、倒计时/纪念日、随机决定器
  • 内存优化：一键回收内存（所有版本）；常驻内存显示、定时回收（Pro/Ultra 开发者设置）
  • 开发者模式（Pro/Ultra）：连点大标题 8 下开启，含功能开关、崩溃日志、数据工具、多开等
  • 附件系统（Ultra）：附件修改器、预设管理器、数据备份工具

数据与保存

所有数据统一保存在程序目录下的 Orbit3_data.json。

  • 退出程序时自动保存
  • 每隔一段时间自动保存（间隔可在设置里改）
  • 极简模式中途退出会结算已学习的时间，不浪费

开发者模式（Pro / Ultra）

在主界面连续点击大标题 8 下 开启，再点 8 下关闭。开启后主菜单出现「开发者模式」按钮。

  • 功能开关：模式 / 任务管理器 / 小功能 / mod / 允许删除「努力的我」/ 多开
  • 开发者源码展示、崩溃日志传输与分析、数据与存档工具、诊断面板、界面调试
  • 内存占用显示、定时自动内存优化、更新日志显示方式切换

附件系统（Ultra）

主菜单「附件系统」里可下载 3 个独立小工具到 attachments 文件夹：

  • 自定义附件修改器：类似 IDE，编辑 rw / fqm / almfq 文件，带常用字符插入
  • 预设文件管理器：浏览、新建、编辑 .rw 预设文件
  • 数据备份工具：一键备份 / 恢复 Orbit3_data.json
