# 4.0 / Orbit1

Orbit 系列第一版，含 mods / almfq。

## 文件

- `source/orbit1.pyw`  主程序
- `source/icon.ico`  图标
- `source/mods/`  皮肤包
- `source/almfq/`  冲突规则
- `source/old/`  历史源码（数字版本命名）

## 运行

Windows + Python 3.8+，双击 `source/orbit1.pyw`。本版本没有 exe，未建空的 exe 目录。

## 数据

个人 JSON、备份与缓存未纳入；首次运行会生成新数据。
